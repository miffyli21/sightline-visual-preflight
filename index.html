    Sightline v0.1.0-alpha.2 · 本地浏览器工具。模拟结果用于设计审查，不替代真实用户测试、屏幕阅读器测试或正式合规审计。

    HOW TO USE

    三分钟，给一张成品图多看几眼。

    1. 导入已经导出的海报、社媒图或 UI 截图。
    2. 切换小屏、灰阶与不同色觉模拟，观察关键信息是否还成立。
    3. 框选标题、价格、按钮等重点，再用 A / B 取色测实际对比度。
    4. 把本地预检记录附在设计验收或交付里。

    所有处理均在当前浏览器完成，不会上传图片。
