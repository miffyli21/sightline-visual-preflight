# Changelog

All notable changes are documented here.

## v0.1.0-alpha.1 — 2026-08-12

First public-alpha candidate.

- Local image import for PNG, JPG, WebP, GIF, and SVG;
- Original, small-screen, grayscale, red-weak, green-weak, and blue-weak views;
- Key-message area marking;
- Pixel A/B contrast checks with plain-language reference guidance;
- Dominant-color confusion-risk hints;
- Local PNG and JSON exports;
- Public validation examples, tester script, privacy guidance, and issue templates.

### Known limitations

- The color-vision views are approximate design-review simulations;
- The tool does not perform OCR or automatically understand which text is important;
- Contrast only describes the pixels the reviewer samples;
- Exported PNG and JSON are review artifacts, not formal conformance reports.
